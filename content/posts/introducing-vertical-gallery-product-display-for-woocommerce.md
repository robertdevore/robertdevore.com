I’m thrilled to announce the release of my latest WordPress plugin, **[Vertical Gallery Product Display for WooCommerce®](https://github.com/robertdevore/vertical-gallery-product-display)**. 

This plugin is designed to enhance the shopping experience by transforming the WooCommerce® product gallery into a sleek vertical layout, with customization options to place the gallery on the left or right side of the main product image.

![Vertical Gallery Product Display for WooCommerce®](/assets/legacy-images/vertical_gallery_product_display_for_woocommerce_example.webp)

### Why Build This Plugin?

The idea for this plugin came from observing how product galleries are presented in WooCommerce® stores. 

While the default horizontal layout works fine, it often lacks the flexibility and elegance that modern e-commerce sites demand. 

A vertical gallery layout not only looks better but also makes navigation smoother, especially on larger screens.

But there’s another reason I decided to release this plugin. 

I’ve noticed a growing trend in the WooCommerce® ecosystem: developers creating basic plugins like this, slapping a $19 price tag on them, and locking features behind paywalls. 

While I understand the need for developers to earn a living (we all do), I find it frustrating when users are essentially penny-pinched for features that should be freely available.

I’m not here to knock anyone’s hustle, but I’m taking a different route. 

This plugin is free – no hidden costs, no paywalls. 

It’s my way of giving back to the WordPress® community and helping WooCommerce® store owners improve their product pages without spending extra.

![vertical-gallery-product-display-for-woocommerce-settings](/assets/legacy-images/vertical_gallery_product_display_for_woocommerce_settings.webp)

### How to Use Vertical Gallery Product Display

Getting started with this plugin is straightforward:

  1. **Install the Plugin** : Download it from [GitHub](https://github.com/robertdevore/vertical-gallery-product-display) or upload the zip file through your WordPress admin.
  2. **Activate the Plugin** : Go to **Plugins > Installed Plugins** and activate it.
  3. **Configure the Settings** : 
     * Navigate to **WooCommerce > Vertical Gallery** in your WordPress® dashboard.
     * Choose whether you want the gallery on the left or right side.
     * Save your settings.
  4. **See the Changes** : Visit a single product page, and your new vertical gallery layout will be live!



### Behind the Scenes: Building a Plugin Like This

For those curious about how this plugin works, it uses WordPress® hooks and actions to integrate seamlessly with WooCommerce®. 

The CSS and JavaScript files provide the styling and functionality for the vertical layout, and a simple settings page allows users to customize the gallery position.

If you’re a developer, here’s a breakdown of the tools and techniques used:

  * **WordPress Core APIs** : The plugin leverages the admin settings and enqueue scripts APIs to provide a polished experience.
  * **Localization** : It’s fully translatable, so anyone can use it in their language.
  * **Performance** : It’s lightweight and doesn’t slow down your site.



### Why Free Matters

The decision to release this plugin for free isn’t just about standing out; it’s about values. 

I’ve seen too many examples of basic functionality being sold at prices that add up for users running multiple sites. 

**I believe in empowering users, not nickel-and-diming them.**

By releasing this plugin for free, I hope to inspire other developers to reconsider their approach. Let’s create tools that truly benefit users without creating financial barriers.
