This means there is going to be an influx of websites being built for new businesses with WordPress in the upcoming years. It doesn't matter if you're the cannabis business owner or a freelancer/agency setting up that biz owners website, you should know what WordPress plugins will help make the website you're building solid, secure and professionally focused. This article will cover the WordPress plugins that you should know about and utilize in 2017.

## WordPress SEO Plugins

When it comes to search engine optimization, WordPress does a good job setting you up with a good SEO Base. But when it comes to putting all of the SEO tools needed into place, Yoast does a great job. It's the SEO plugin I use on my personal websites and the WordPress plugin I recommend to all of my clients and friends. It's the plugin I would recommend for you as well.

### [Yoast SEO](https://wordpress.org/plugins/wordpress-seo/)

[![Yoast SEO plugin for WordPress](/assets/legacy-images/yoast_seo.webp)](https://wordpress.org/plugins/wordpress-seo/) **Additional options:**

  * [All In One SEO](https://wordpress.org/plugins/all-in-one-seo-pack/)
  * [SEO Wizard](https://wordpress.org/plugins/seo-wizard/)
  * [SEO Images](https://wordpress.org/plugins/seo-image/)



## WordPress Backup Plugins

If you've built websites for more than a year or two, I'm sure you've run into the moment when a website you were working on collapses into rubble and you didn't have a backup plan. Maybe it was just me 🙂 Regardless, having a back up of your website is top priority if you treat your website like a business in any type of way. With the proper backups, you can have your website go from _down for the count_ , to back up and running in a matter of minutes. My recommendation to anyone who ever asks is **UpdraftPlus**. It's got everything you need in a backup solution and for most users, the free options are more than enough.

### [UpdraftPlus](https://wordpress.org/plugins/updraftplus/)

[![UpdraftPlus Backup plugin for WordPress](/assets/legacy-images/updraft_plus.webp)](https://wordpress.org/plugins/updraftplus/) **Additional options:**

  * [WP-DB-Backup](https://wordpress.org/plugins/wp-db-backup/)
  * [Duplicator](https://wordpress.org/plugins/duplicator/)
  * [BackupBuddy](https://ithemes.com/purchase/backupbuddy/)



## WordPress Security Plugins

A hot topic in recent years, web security WordPress plugins needs to be a key tool in your websites toolbox. I've been a personal fan of the Sucuri plugin for my websites but have recently been testing out Wordfence and love it. It seems over a million people think so too, making it the most downloaded security plugin for WordPress.

### [Wordfence](https://wordpress.org/plugins/wordfence/)

[![Wordfence Security plugin for WordPress](/assets/legacy-images/wordfence_security.webp)](https://wordpress.org/plugins/wordfence/) **Additional options:**

  * [Sucuri Security](https://wordpress.org/plugins/sucuri-scanner/)
  * [All In One WP Security & Firewall](https://wordpress.org/plugins/all-in-one-wp-security-and-firewall/)
  * [BulletProof Security](https://wordpress.org/plugins/bulletproof-security/)

## WordPress Social Media Plugins

Every day we become more attached to our phones, mainly through the use of Apps, many of them being social media related. Your website is no different, and should be looking at social media as an extension of itself, interacting with users, sharing content and gaining followers and website visitors. The easiest way is to set up a WordPress plugin that adds sharing buttons to your content. MashShare is one of the top social media plugins, giving you the ability to add social media sharing buttons in a variety of ways.

### [MashShare](https://wordpress.org/plugins/mashsharer/)

[![MashShare social media sharing plugin for WordPress](/assets/legacy-images/mashshare_socia_media_buttons.webp)](https://wordpress.org/plugins/mashsharer/) **Additional options:**
