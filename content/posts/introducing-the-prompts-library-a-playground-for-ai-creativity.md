Over the last few months, I’ve been experimenting with ways to push generative AI further – not just to create images, but to **design tools** that help you _consistently_ create great ones.

That’s where the **[Prompts Library](https://prompts.robertdevore.com)** comes in.

It’s a curated collection of high-performance JSON prompts I’ve written and refined for use with AI image generation. 

Each one is built around a specific visual style or creative need – whether you’re designing icons, mocking up thumbnails, or just messing around with nostalgic art.

And this isn’t just a dump of random prompts. These are:

  * ✅ **Structured**
  * ✅ **Repeatable**
  * ✅ **Styled for real-world use**



Every prompt comes with visual examples, clear usage examples, and plenty of room to remix.

## What’s Inside (So Far)

Here’s a sampling of what you’ll find live on the library now:

  * **[🔒 Glowing Neon Lock](https://prompts.robertdevore.com/blog/glowing-neon-icon-json-prompt/)** – Design bold, high-impact security icons with digital glow.
  * **[📐 Isometric 3D Icons](https://prompts.robertdevore.com/blog/isometric-3d-icon-json-prompt-for-ai-generated-designs/)** – Create crisp, dimensional assets for UI kits or onboarding flows.
  * **[🎖️ Military Patch Generator](https://prompts.robertdevore.com/blog/top-secret-military-patches-json-prompt/)** – Generate photorealistic embroidered patches with tactical flair.
  * **[💻 Metallic Sci-Fi HUD](https://prompts.robertdevore.com/blog/metallic-sci-fi-hud/)** – Futuristic UI elements and sci-fi-inspired iconography.
  * **[📺 YouTube Thumbnail Prompts](https://prompts.robertdevore.com/blog/youtube-thumbnail-generation-with-ai-json-prompts/)** – Skip the Canva struggle and generate eye-catching thumbnails fast.
  * **[🟡 Simpsons Characters](https://prompts.robertdevore.com/blog/simpsons-character-json-prompts-for-ai-generation/)** – Drop yourself (or anyone) into Springfield with these style-matched prompts.
  * **[💥 WWF Action Figure Blister Packs](https://prompts.robertdevore.com/blog/wwf-action-figure-blister-pack-json-prompt/)** – The one that started it all – fully retro, fully absurd, and way too fun.



## Who’s It For?

Designers, marketers, devs, meme-makers, nostalgia nerds – anyone who wants to **generate high-quality visuals with control**. 

This isn’t “click and pray” AI art. Each prompt is a creative lever that can be pulled with minimal effort.

## Got an Idea? I’m Taking Requests.

If there’s a visual style or idea you want turned into a reusable JSON prompt – **hit me up**. 

I’m keeping this project open-ended on purpose. 

The goal is to make the library genuinely useful (and way more fun than scrolling through generic styles).

Start exploring at [prompts.robertdevore.com](https://prompts.robertdevore.com), and feel free to steal, remix, and request.

Let’s make better stuff, faster.
