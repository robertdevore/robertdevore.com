Today marks the release of **IMG A11Y** , a free WordPress® plugin designed to make image accessibility compliance easier than ever. 

I created [IMG A11Y](https://github.com/robertdevore/img-a11y) to help WordPress users address one of the most important aspects of accessibility: ensuring all images have proper alt text or are marked as decorative.

![IMG A11Y - Overview](/assets/legacy-images/img_a11y_settings.webp)

#### Key Features

IMG A11Y is packed with functionality aimed at simplifying and enhancing accessibility efforts:

  1. **Alt Text Validation**  
Save attempts in both the Classic and Gutenberg editors are blocked if any images in the content lack alt text or aren’t marked as decorative. This ensures your content always meets accessibility standards.
  2. **Decorative Image Marking**  
Images that are purely decorative can be marked as such directly in the Media Library. This eliminates the need for alt text while adhering to accessibility guidelines.
  3. **Admin Dashboard Overview**  
A dedicated admin page provides an overview of your images, including those missing alt text or marked as decorative. This makes it easy to identify and address gaps in accessibility.
  4. **Inline Alt Text Editing**  
Update alt text directly within the plugin’s admin interface, streamlining your workflow.
  5. **Custom Admin Notices**  
Receive clear, actionable notifications when alt text is missing, ensuring accessibility standards are always maintained.
  6. **Full WordPress Integration**  
The plugin seamlessly integrates with WordPress, working with both editors, the Media Library, and the admin interface.

![IMG A11Y - Publishing failed](/assets/legacy-images/img_a11y_publishing_failed_1024x672.webp)

#### Why I Built IMG A11Y

Accessibility matters. Whether you’re running a personal blog or managing a large website, creating accessible content ensures that everyone can engage with your site. 

I wanted to develop a tool that simplifies accessibility for WordPress® users, especially when it comes to managing images.

#### How to Get Started

Getting started is simple:

  1. Install IMG A11Y from your WordPress® admin dashboard by uploading the plugin ZIP.
  2. Activate the plugin and start managing your images.
  3. Use the Media Library or the plugin’s admin interface to ensure all images are accessible.



#### What’s Next for IMG A11Y

While this release provides powerful tools for image accessibility, I’m already planning future enhancements, including:

  * Bulk editing capabilities for alt text and decorative image status.
  * Comprehensive accessibility reports to help you monitor your entire site.
  * Localization support to make the plugin accessible to users around the world.
