I’m excited to announce the release of ANOTHER new free WordPress® plugin for 💪💯

The free **[Module Usage Tracker for WP Bakery](https://github.com/robertdevore/module-usage-tracker-for-wp-bakery)** plugin is a new tool for anyone looking to get a closer view of how WP Bakery modules are being used across a WordPress® site. 

This plugin was created to help site owners, developers, and content creators analyze and track WP Bakery module usage, providing valuable insights into module popularity and page utilization.

![Module Usage Tracker for WP Bakery settings page](/assets/legacy-images/module_usage_tracker_for_wp_bakery_settings.webp)

## Why Use Module Usage Tracker for WP Bakery?

[WP Bakery](https://wpbakery.com/) offers an extensive range of modules to build pages quickly, but as pages and sites grow, it can become challenging to know exactly when, where and how frequently each module is used. 

[The Module Usage Tracker for WP Bakery](https://github.com/robertdevore/module-usage-tracker-for-wp-bakery) plugin solves this problem by organizing module usage data into a comprehensive dashboard.

This make it easy to understand the impact and frequency of each WP Bakery module on your site.

## Key Features

Here’s a quick overview of what the Module Usage Tracker offers:

  * **Detailed Module Dashboard** : Easily view all WP Bakery modules and their usage across your site. The dashboard provides an overview of each module, including how often it’s used and on which pages.
  * **Module Usage Filtering** : Quickly filter modules by usage level: **High Usage** (10 or more instances), **Medium Usage** (5-9 instances), or **Low Usage** (fewer than 5 instances). This feature makes it easy to identify the most and least popular modules on your site.
  * **Detailed Module Analysis with AJAX-Powered Modal** : For each module, you can access a list of all pages where it’s used. With a single click, the modal shows specific pages, along with links for easy editing.
  * **Search Functionality** : Quickly find specific modules by name with the search box, so you can easily locate and analyze individual modules.



## How It Works

Once activated, Module Usage Tracker for WP Bakery will scan and compile usage data for all WP Bakery modules on your site. 

The plugin then generates an organized dashboard displaying usage counts, a filter dropdown, and a search box for quick navigation.

When you click **View Details** for a module, an AJAX-powered modal will load, showing the total usage count and a list of unique pages using that module. 

Each page in the modal includes an edit link, so you can jump right into the page editor if you need to make adjustments.

## Who Will Benefit from This Plugin?

  * **Site Owners and Admins** : Gain insights into which WP Bakery modules are being used most frequently, allowing for informed decisions about module usage and site optimization.
  * **Content Creators** : See an at-a-glance overview of the most popular modules, and identify which pages are utilizing specific design elements.
  * **Developers** : Quickly find where each module is used across a site, useful when planning redesigns, maintenance, or performance optimizations.



## Get Started Today

To get started, simply download the plugin from the [Module Usage Tracker for WP Bakery GitHubpage](https://github.com/robertdevore/module-usage-tracker-for-wp-bakery/), install it on your site, and activate it. 

The **Module Tracker** will appear in the WordPress admin menu, ready to provide you with actionable insights that you and your team need 🚀
