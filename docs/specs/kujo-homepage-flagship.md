## Goal

Reorganize the homepage Kujo flagship section so its single title, supporting subtitle, and calls to action sit together on the right while the section identity remains on the left, and enforce the Departure Mono face for homepage titles, project names, boxes, and major section surfaces.

## Background

The current homepage flagship markup separates the Kujo heading/subtitle from its identity and actions, making the focus area harder to scan. The site already ships Departure Mono as the mono token but does not consistently apply it to homepage headings and large boxed surfaces.

## Scope

Update templates/page-home.html and the site-specific homepage CSS in assets/css/site.css; add deterministic homepage structure and typography checks; capture a Lens desktop/mobile artifact with before/after visual comparison.

## Non-Goals

- Changing homepage copy, routes, project links, or the global SiteKit/vendor artifacts.
- Changing the body copy font or applying a new font asset.
- Publishing or deploying the site.

## Acceptance Criteria

1. The homepage Kujo flagship section has one right-hand content block containing the single h2 title, its subtitle paragraph, and both project action buttons.
2. The left-hand flagship identity contains the section index, Kujo signal, and Kujo name without duplicating the flagship title or subtitle.
3. The flagship layout remains two-column on desktop and collapses to one readable column at the existing responsive breakpoint.
4. Homepage h1-h4 title/name elements and the flagship, selected-system cards, and operating-principle boxes explicitly use var(--sk-font-mono), which resolves to Departure Mono.
5. The generated homepage contains the new flagship structure, has no horizontal overflow, and preserves the Kujo project and source links.
6. A Lens artifact records desktop and mobile screenshots, reports the homepage assertions, and includes a before/after visual comparison.
