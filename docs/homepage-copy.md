## 3. Operating principles

### Section label

**03 / Operating principles**

### Heading

**How I build.**

### Principle 1

#### Label

**CONTEXT**

#### Title

**Make state visible**

#### Description

Systems should show their assumptions, inputs, outputs, and failures without requiring a private oral tradition.

### Principle 2

#### Label

**CONTROL**

#### Title

**Keep work inspectable**

#### Description

Automation earns trust when a person can replay the path, verify the evidence, and intervene cleanly.

### Principle 3

#### Label

**CRAFT**

#### Title

**Ship the record**

#### Description

Useful tools include docs, examples, receipts, and release gates as part of the product surface.

### Principle 4

#### Label

**LEADERSHIP**

#### Title

**Pressure-test the room**

#### Description

Good systems work includes the people operating the system, especially when the work gets loud.

### Related link

For the leadership side of this operating style, read **LEAP: The Code of Extreme Leadership**.
